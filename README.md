# OutlineCistern

OutlineCistern enables real-time data processing and auto-scaling capabilities within a hybrid, distributed system architecture.

OutlineCistern is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/OutlineCistern.git`
2. `cd OutlineCistern`
3. Install in editable mode: `pip install -e .`

## Configuration

OutlineCistern is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
